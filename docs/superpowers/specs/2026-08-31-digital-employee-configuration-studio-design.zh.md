# 数字员工配置工作室设计

[English](2026-08-31-digital-employee-configuration-studio-design.md) | 中文

## 目的

为现有数字员工管理界面增加本机管理员配置工作室。

普通用户继续通过员工工作区创建、使用和升级员工实例。

管理员通过配置工作室创建并发布不可变的员工模板版本。

## 产品区域

现有员工工作区继续负责员工实例生命周期、员工聊天、记忆检查、专家任务检查、审计、导入/导出和模板升级。

配置工作室增加模板草稿、验证、预览、版本历史和发布。

第一版中，该工作室仅对本机管理员可见。

## 模板草稿

每个草稿包含：

- 基本信息：名称、标识符、描述、宣传图和建议使用场景。
- 主 agent 配置：`AGENT.md`、行为、模型选择、工作目录、审批策略和默认能力集合。
- 专家 agent 配置：专家指令、允许使用的 skill、tool、MCP client、记忆访问和委派限制。
- Skill：对已安装或市场提供的 skill 的引用。
- Tool：显式允许的 tool，以及其已记录的输入、结果和审批影响。
- MCP client：对已注册配置的引用，凭据不存储在浏览器中。
- 记忆：员工创建时的种子记忆和长期记忆策略。

## 生命周期

管理员依次执行：

`draft -> validation -> sandbox preview -> published version`

发布会创建不可变版本。

编辑已发布版本会启动新的草稿。

员工实例保持当前模板版本，直到管理员或用户通过既有升级流程应用可用升级。

## 验证与预览

验证会拒绝不完整或不安全的配置，包括：

- 重复的 MCP server 名称。
- 缺失的 skill、tool 或 MCP 引用。
- 超出父 agent 权限的专家权限。
- 不受支持的专家委派深度。
- 无效的模板标识符。
- 缺失的必需 agent 指令。
- 嵌入草稿的敏感 MCP 凭据。

预览会创建隔离的临时员工实例和会话。

预览数据不会修改已发布模板、员工实例或持久化员工记忆。

## 第一版限制

第一版仅在本机由单一管理员使用。

它不增加认证、组织、协作编辑、审批工作流或基于浏览器的密钥管理。

市场 ZIP 包仍然是 skill 和模板的来源，但不是模板编辑的表示形式。
