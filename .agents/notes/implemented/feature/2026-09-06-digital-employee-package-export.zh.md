# Agent Note: 员工包导出与导入

状态：已实现

[English](2026-09-06-digital-employee-package-export.md) | 中文

## 问题

已发布的数字员工模板只能在本地使用。把员工分发到另一台 Host 需要手工拷贝文件并重新注册。

## 决策

`employee` 成为第六种市场包 kind。`employee-package.json` 声明模板（展示元数据、指令文件、专家、委托策略）以及记录所需市场包的引用清单。exportTemplate 用市场 Ed25519 机制把已发布的本地模板序列化为签名 zip；importTemplate 校验归档（文件哈希、可选发布者信任），把指令与专家文件写入模板根目录、重新注册模板，并把缺失的市场引用按 kind 分组报告为诊断。解析器拒绝不在签名文件表中的指令与专家路径。

## 已否决的备选方案

- **把市场资产内联到员工包中**——重复六种市场格式并破坏资产版本独立性。
- **导入时自动安装市场包**——用户应通过市场显式安装缺失的包。

## 后果

员工包是声明式的，绝不携带 provider 代码。导入不会自动安装；缺失引用以按市场 kind 分组的可操作诊断呈现。
