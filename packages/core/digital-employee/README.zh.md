# @deepseek-ai/dsh-digital-employee

[English](README.md) | 中文

可复用数字员工模板与持久化员工实例的 Service Definition。该服务负责在 effect 作用域内注册模板，并把可变实例、记忆、生命周期与审计操作委托给一个已配置的提供方。

模板固定到精确版本，并声明身份、个性、`AGENTS.md` 来源、preset、显式能力、具名专家、记忆访问方式与委派限制。提供方必须在创建任务 Session 前解析活跃实例；缺少模板版本或必需引用时直接失败，不会选择替代项。

## 服务

`ctx.digitalEmployees.registerTemplate()` 验证并注册一个不可变模板版本，返回的 disposer 会移除这项精确贡献。`configureProvider()` 安装唯一的持久化提供方，负责实例、记忆、解析与审计操作。

能力数组是 allowlist。消费方通过模板声明、实例授权与继承的 Agent 权限三者取交集，计算有效的子级权限。

模板是可执行定义，不是可变员工记录。更新模板会注册另一个不可变版本；现有员工仍固定到原版本，直到显式升级先预览能力变化，再应用经审查的授权。

## 实例与生命周期

提供方创建非活跃实例；每个实例拥有独立的 ID、名称、个性覆盖、授权、记忆与审计历史。生命周期为 `inactive` → `active` → `inactive` 或 `deleting`；只有进入 `deleting` 且自有工作全部结束后，才允许移除。

导出产物不含凭据，并保留可移植的员工数据。导入会分配一个新的非活跃实例，而不是恢复来源实例的身份。

员工拥有的根 Session 会在必读的 `digital-employee/identity` 事件中记录创建时的员工 ID、模板 ID 与版本、解析后组合 ID、显示名称和个性。`projectDigitalEmployeeOwnership()` 从日志恢复该快照，因此之后的重命名、升级、停用或移除不会改变历史归属。

## 记忆记录

任务记忆携带稳定的员工任务 ID，并只属于该次工作，除非被提升。会话记忆携带所属 Session ID，并随该 Session 重建。长期记忆独立属于员工，不依附于单个 Session。

每条记忆记录都包含员工归属、内容、标签、敏感标记、来源与可选过期时间。检索请求通过显式结果上限选择该员工拥有的记忆作用域。长期写入先成为提升候选项，可指定保留天数，并返回明确的已接受记录或拒绝原因。

## 模型体验

### Consumer 投影

#### 模型看到的内容

Consumer 从已记录的 Session 事件渲染解析后的身份、`AGENTS.md` 指令、有界记忆与专家结果。

#### Token 影响

Definition 本身不直接增加 token；Consumer 选择的指令与记忆决定请求中增加的内容。

#### KV Cache 影响

模板版本、实例个性、权限或检索到的记忆发生变化时，Consumer 投影可能替换员工专属的提示词前缀。

## 已知限制与后续工作

- **不内置提供方**：本包只定义服务与模板注册表；实例持久化与任务组装需要另行挂载提供方和 Consumer。
