# `@deepseek-ai/dsh-client-ui-skill-market`

[English](README.md) | 中文

客户端本地化技能市场设置区的浏览器侧参考文档。

## 组合

插件通过客户端 slots 注册本地化词典、设置导航项和设置区。它调用 `@deepseek-ai/dsh-api-remotes` 生成的 `ctx.remote.skillMarket` 命名空间；压缩包校验、所有权判定和文件系统变更仍由宿主负责。

该设置区只展示宿主返回的受管清单。由文件系统发现的手工管理技能不在此视图中，也不能在此升级或卸载。

## 清单与搜索

挂载时和每次成功变更后，store 都会请求权威清单。UI 分别呈现空闲、加载、就绪、空清单和错误状态，并支持重试。

搜索在本地执行，不区分大小写，并覆盖技能名称、描述、作者和标签。卡片会展示版本、作者、标签以及可用的宣传图。图片从宿主校验过的 PNG、JPEG、WebP 或 GIF 字节延迟加载；加载中、缺失和失败状态使用尺寸稳定的占位内容。

## 上传与升级

上传控件接受一个 `.zip` 文件，并在编码前拒绝超过 10 MiB 的文件。宿主会重复全部安全检查，包括严格 ZIP 布局、描述文件元数据、路径安全、256 个文件与 30 MiB 解压限制，以及 2 MiB 宣传图限制。

首次请求不携带替换意图。安装成功后会刷新清单并显示可关闭通知。只有结构化的 `managed-upgrade-required` 结果会打开确认流程并保留编码后的候选包；确认操作会带明确替换意图重新提交，取消或设置区销毁会释放候选包。非受管冲突和不兼容清单只显示拒绝状态，不提供强制覆盖操作。

该设置区分别提供作者模板与可直接安装的测试示例。作者模板包含占位符与发布指导。`marketplace-test-*` 压缩包使用固定 fixture 标识进行本地验证；Tool 示例仍要求显式信任其测试专用发布者。

## 卸载

卸载始终需要确认。请求进行期间，对应操作会禁用，设置区会显示进度。成功后释放对应图片数据、关闭确认、刷新清单并显示结果状态。结构化的所有权失败或不存在失败会保持可见，且客户端不会假定宿主已经改变目标。

## 异步生命周期

清单、上传、卸载和逐图片操作均使用 generation guard。被后续请求取代的响应不能覆盖较新状态；设置区销毁后不再发布状态，并会释放保留的压缩包和图片数据。

已声明的市场失败按可辨识字段映射为本地化消息。传输、取消和意外失败进入通用操作失败状态并记录诊断；浏览器绝不解析宿主错误文本。

## 模型体验

不存在模型可见性，因为市场上传和变更不会增加提示词区段、工具、会话事件或请求输入。

#### KV Cache 影响

市场交互不会添加或修改请求历史。

## 已知限制与延后工作

- 浏览器通过共享 `/api` Remote 载体发送 base64 JSON，不会解压压缩包或写入宿主文件。
- 第一版支持本地 ZIP 上传、每个技能一张宣传图、手动受管升级和确认卸载。
- UI 不提供托管注册表、URL 下载、评分、签名、依赖解析、自动更新，也不安装项目或预设技能。
- 市场交互不会创建会话事件、改变模型可见的提示词或请求，也不会改变任一 SDK。
