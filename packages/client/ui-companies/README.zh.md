# @deepseek-ai/dsh-client-ui-companies

[English](README.md) | 中文

浏览器端 3D 公司园区控制台。侧栏底部「组织」下拉（本包持有，「数字员工」项委托给数字员工工作区）打开全屏 `shell.overlay` 表面，内含两个 Three.js 场景：园区为小区化规划——环内四个规划小区（一区..四区），各带绿篱围合与「小区门口」，门口支路接入主路网（环路+十字主路+接驳路+外围网格），小区内车道通至每栋房子门口、房前小径到户，房子朝向车道并按地块封顶（屋顶色编码分类、尺寸随人数缩放、宣传图上广告牌、地址上路牌）；外围是一座会动的城市——虚线车道马路上沿路网随机游走的汽车（每次到路口随机选路不折返）、反相循环 绿→黄→红 的红绿灯、电车、货运火车、高架桥上方向/速度/发车间隔随机的 高铁 与 地铁（含「地铁」出入口小屋）、带公路桥的河流与成片森林（全部为纯装饰，不参与交互）；内部场景为带隔间装修的办公平面——齐腰外围隔墙、南侧对开玻璃大门（大门）、走廊北侧每部门一间隔墙办公室、前区西侧按部门名匹配的玻璃隔间「总裁办公室」，以及固定的茶水区（操作台/咖啡机/饮水机）、休息区（地毯/对坐沙发/茶几/绿植）、厕所（隔间/洗手池）与吸烟区（长凳/烟灰缸立柱）。员工活在碰撞世界里：每件设施（工位、电脑、操作台、长凳、洗手池）与每名行走者都登记定位 AABB；空闲员工沿走廊在各功能区之间游走，绕家具滑行、遇同事让行，忙碌翻转（既有会话/任务推导）让他们径直走回工位点亮屏幕。拥挤与受阻滋养运行时情绪（😡 标记），暴怒路过者会破坏可破坏设施（纯视觉歪斜/倒塌，刷新重置）；每次到达功能区上报进员工的持久到访史（经群网关落 `whereabouts.json`——实例跨刷新持续存在的证据），每张工位电脑与员工绑定，在忙碌屏旁绘制其最近真实会话消息。墙体是实体：房间隔墙、总裁玻璃墙、外围墙与大门门体均登记为阻挡分段、门洞可通行——员工只经门洞穿行，滑行与退让不越墙，自己的桌与电脑不再阻挡本人。车辆在同边跟车之外增加对向让行，双向排队互不穿过（出生保持刷新随机）；多排部门办公室侧向开门进入加宽的排间走廊。每家公司持有独立的 `skinId`，在五套程序化皮肤（默认 现代简约、中式庭院、科技霓虹、田园木屋、玻璃幕墙）中选一；皮肤同时驱动两层——园区侧的房子形态、配色与装饰，内部的地面、隔墙、家具、桌面与灯光——在「公司皮肤」选择器中切换即热换当前场景，无需刷新页面。在座员工在 在忙 与 空闲 之间实时翻转（会话型忙碌搭现有 WebSocket 会话状态位；任务型结论经 5 秒楼层轮询刷新）。`three` 内联进客户端 bundle（无 GLTF 资产——几何全部程序化生成）。点击在座员工弹出详情面板并可直达数字员工工作区；点击空工位打开该部门的绑定选择器。

控制台占用 `shell.overlay`（附加位）而非 `shell.application`（被数字员工工作区占用的单座位，第二注册者只能遮蔽它）。

## Model Experience

无。本包渲染控制台，不贡献提示词、工具或会话事件。

#### KV Cache effect

无；控制台状态不进入模型请求。

## Known Limitations and Deferred Work

- **无逐座位镜头** —— 点击员工只弹详情面板，不把镜头动画对准其工位。
- **广告牌纹理懒加载** —— 宣传图在园区首帧后才出现。
